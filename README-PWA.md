# 國護り PWA公開版

「國護り ― 四十八の神託 ―」をiPhone Safari・Android Chromeから利用し、ホーム画面へ追加できるようにした公開用ファイル一式です。

## 公開に必要な条件

- HTTPSで配信すること（GitHub PagesはHTTPS対応）
- このフォルダの中身を、フォルダ構成を変えずに公開先へ配置すること
- `service-worker.js` をアプリの `index.html` と同じ階層へ置くこと

## GitHub Pagesへ配置する場合

このフォルダ内の全ファイルを、公開用リポジトリのルートへアップロードします。リポジトリ名を通常名にしたプロジェクトサイトでも、相対パスを使用しているため動作します。

## iPhoneでホーム画面へ追加

1. Safariで公開URLを開く
2. 共有ボタンをタップ
3. 「ホーム画面に追加」を選ぶ
4. 「追加」をタップ

## Androidでホーム画面へ追加

1. Chromeで公開URLを開く
2. ブラウザのメニューを開く
3. 「アプリをインストール」または「ホーム画面に追加」を選ぶ

## 更新時の注意

HTML、CSS、JavaScript、画像を更新した場合は、`service-worker.js` の `CACHE_NAME` を新しい値へ変更します。変更しないと、利用者の端末に以前のファイルが残る場合があります。
